## 🚀 Quick Start

### 1. Install Dependencies
```bash
cd Shailender_Portfolio
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
The portfolio will start instantly at `http://localhost:3000` (or `http://localhost:5173`).

### 3. Production Build
```bash
npm run build
```
Creates an optimized static bundle in the `dist/` directory ready to deploy on **Vercel**, **Netlify**, or **GitHub Pages**.

### 4. Preview Production Build Locally
```bash
npm run preview
```
